💻 CÓDIGO PARA MICRO:BIT

Tu micro:bit debe enviar datos por serial. Aquí tienes ejemplos básicos:

JavaScript (MakeCode): 
// Enviar valor del acelerómetro
basic.forever(function () {
    serial.writeNumber(input.acceleration(Dimension.X))
    serial.writeLine("")
    basic.pause(100)  // 100ms = 10 datos/segundo
})
Python (MicroPython): 
# Enviar valor de temperatura
from microbit import *

while True:
    valor = temperature()
    print(valor)
    sleep(100)

⚠️ IMPORTANTE:

  • Envía SOLO EL NÚMERO, sin texto adicional
  • Usa serial.writeNumber() en JavaScript o print() en Python
  • Termina cada valor con salto de línea (serial.writeLine("") o automático con print())
  • Ajusta basic.pause() o sleep() según la frecuencia deseada

📹 VIDEO SINCRONIZADO

El sistema graba video del experimento y lo sincroniza con los datos:

  • Activa la cámara ANTES de capturar datos
  • Al hacer clic en CAPTURAR, inicia video + datos simultáneamente
  • Cada dato tiene un timestamp asociado al video
  • Click en botón ▶ en la tabla para ver ese momento exacto
  • El video se reproduce desde el instante del punto seleccionado

🎯 EJEMPLOS DE SENSORES

Acelerómetro (X, Y o Z): 
basic.forever(function () {
    serial.writeNumber(input.acceleration(Dimension.X))
    serial.writeLine("")
    basic.pause(50)
})
Nivel de luz: 
basic.forever(function () {
    serial.writeNumber(input.lightLevel())
    serial.writeLine("")
    basic.pause(100)
})
Brújula (orientación): 
basic.forever(function () {
    serial.writeNumber(input.compassHeading())
    serial.writeLine("")
    basic.pause(100)
})
Sensor analógico (Pin P0): 
basic.forever(function () {
    let valor = pins.analogReadPin(AnalogPin.P0)
    serial.writeNumber(valor)
    serial.writeLine("")
    basic.pause(100)
})

⚙️ REQUISITOS DEL SISTEMA

  • Navegador: Chrome, Edge u Opera (con Web Serial API)
  • Sistema: Windows, macOS o Linux
  • Hardware: micro:bit v1 o v2 con cable USB
  • Webcam: Opcional, para grabación de video
  • Conexión: No requiere internet una vez cargada la página

❓ SOLUCIÓN DE PROBLEMAS

No aparece el puerto al conectar:

  • Verifica que el cable USB esté bien conectado
  • Prueba con otro puerto USB
  • Reinicia el navegador

No llegan datos:

  • Asegúrate de que el código esté corriendo en la micro:bit
  • Verifica que uses serial.writeNumber() + serial.writeLine("")
  • No envíes texto, solo números

La cámara no funciona:

  • Permite el acceso a la cámara cuando el navegador lo solicite
  • Verifica que otra aplicación no esté usando la cámara
  • Prueba en modo incógnito del navegador

El video y los datos no coinciden:

  • Activa la cámara ANTES de capturar datos
  • Ambos deben iniciar con el mismo botón CAPTURAR
